# Third-party notices

## @alenaksu/json-viewer 2.1.2

Pulsar JSON Viewer is an extension layer built on `@alenaksu/json-viewer`.

Upstream project: https://github.com/alenaksu/json-viewer

Package: https://www.npmjs.com/package/@alenaksu/json-viewer

License: MIT

The upstream component remains responsible for JSON rendering, expansion, collapse, tree focus, keyboard navigation, filtering and search. Pulsar adds checkbox selection, selected JSON extraction, selected copy, selected download and a small toolbar that calls the upstream public methods.

Pulsar does not claim authorship of the upstream JSON rendering component.

## Heroicons

Pulsar's compact toolbar uses familiar outline icon conventions informed by Heroicons from Tailwind Labs. The icons are inlined as SVG so the component does not add a runtime icon dependency.

Project: https://github.com/tailwindlabs/heroicons
