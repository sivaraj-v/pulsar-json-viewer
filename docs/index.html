Objective

A focused layer around a proven tree viewer.

Pulsar keeps the upstream renderer in charge of tree rendering, expansion and keyboard navigation. It adds the workflow teams need when JSON is part of an investigation: accessible selection, fast search, useful exports, fullscreen workspaces and clear themes.

01

Inspect

Keep large payloads readable with native tree behavior and a sticky action toolbar.

02

Focus

Search keys and values, select nested leaves, and preserve the structure around them.

03

Share

Copy or download the whole payload or only the subset relevant to the task.
