Pulsar JSON Viewer

Examples that start small and scale up

Each example uses the same Web Component. The upstream @alenaksu/json-viewer provides the JSON tree while Pulsar adds optional checkbox selection, built-in copy and download, live search navigation, fullscreen mode, and light or dark dashboard themes.
