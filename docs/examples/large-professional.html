Suggested workflow

Debug a large payload without copying everything

Use the sticky search field on the right side of the viewer toolbar while scrolling through the payload. The left icon groups handle tree and data actions, and the far-right icon opens fullscreen mode.

  1. 1Type degraded. Search starts automatically, then use Previous and Next only when you want to move between matches.
  2. 2Expand services and select only the fields needed for debugging.
  3. 3Copy selected JSON for a ticket, chat or incident note.
  4. 4Download the same focused subset as observability-selection.json.
